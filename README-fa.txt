Little Autumn · نسخه ارتقایافته آبان ۱۴۰۵

امکانات افزوده‌شده:
- حفظ کلید ذخیره‌سازی قبلی little-autumn-v1 و مهاجرت افزایشی داده‌های عادت‌ها، تیک‌ها و یادداشت‌ها
- کتابخانه عادت‌ها، توقف/فعال‌سازی، حذف با تأیید، دسته‌بندی و آیکون/رنگ
- برنامه روزهای هفته و بازه روزهای آبان، تغییر برنامه با تاریخچه، روز استراحت
- محاسبه درصد بر اساس روزهای برنامه‌ریزی‌شده
- دفتر خاطرات، mood tracker و افزودن چند عکس به هر روز
- ذخیره عکس‌ها در IndexedDB
- گزارش ماهانه، مرور هفتگی، heatmap، دستاوردها، CSV و PNG
- پشتیبان JSON شامل اطلاعات و عکس‌ها و بازیابی آن
- خروجی PDF خاطرات و گزارش از طریق پنجره چاپ مرورگر (در مقصد چاپ گزینه Save as PDF را انتخاب کنید)
- Undo تغییرات اخیر در همان نشست
- PWA و cache version جدید

نصب/انتشار:
محتویات این پوشه را در ریشه مخزن GitHub جایگزین کنید و commit کنید. GitHub Pages همان آدرس قبلی را به‌روزرسانی می‌کند.

نکته حفظ داده:
نسخه از همان localStorage key یعنی little-autumn-v1 استفاده می‌کند. هنگام ارتقا، localStorage را پاک نکنید و در همان origin و همان مرورگر اپ را باز کنید. پیش از جایگزینی نسخه، اگر نسخه قدیمی هنوز در دسترس است، از داده‌ها اسکرین‌شات یا پشتیبان JSON تهیه کنید؛ نسخه اولیه امکان خروجی JSON نداشت، بنابراین تیک‌ها و یادداشت‌های موجود مستقیماً از همان کلید خوانده می‌شوند.

عکس‌ها از این نسخه به بعد در IndexedDB ذخیره می‌شوند و داخل پشتیبان JSON قرار می‌گیرند. PDF در مرورگر با Print → Save as PDF ساخته می‌شود.


نسخه ۳: امکان جابه‌جایی دستی عادت‌ها با دکمه‌های بالا/پایین اضافه شده است. همچنین در بخش پشتیبان، انتخاب پوشه‌ی مادر و ذخیره‌ی خودکار در ساختار Little Autumn/data ، Little Autumn/habits و Little Autumn/memories/photos اضافه شده است. این قابلیت به پشتیبانی مرورگر از File System Access API نیاز دارد؛ اگر در مرورگر گوشی در دسترس نباشد، پشتیبان JSON راه جایگزین است. برای حفظ داده‌ها، قبل از به‌روزرسانی از پشتیبان JSON خروجی بگیر.
