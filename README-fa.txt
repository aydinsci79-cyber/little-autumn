# Little Autumn 🍂
نسخه‌ی اولیه‌ی اپلیکیشن عادت‌های آبان ۱۴۰۵

## امکانات
- تقویم ماهانه آبان ۱۴۰۵
- افزودن عادت با نام، آیکون و رنگ اختصاصی
- ویرایش عادت‌ها
- ثبت انجام عادت برای هر روز
- نمودار پیشرفت ماهانه و شمارنده روزهای موفق
- یادداشت روزانه
- ذخیره‌ی اطلاعات در حافظه‌ی مرورگر همین دستگاه (localStorage)
- قابلیت نصب به شکل PWA و اجرای آفلاین پس از اولین بارگذاری

## نصب روی گوشی سامسونگ
برای نصب واقعی به‌صورت PWA، فایل‌ها باید روی یک میزبان HTTPS منتشر شوند.
1. محتوای این پوشه را در یک مخزن GitHub قرار بده.
2. در تنظیمات مخزن، بخش Pages را فعال کن و شاخه‌ی اصلی و پوشه‌ی root را انتخاب کن.
3. پس از انتشار، آدرس HTTPS سایت را با Chrome یا Samsung Internet روی گوشی باز کن.
4. از منوی مرورگر گزینه‌ی Install app یا Add to Home screen را بزن.

## نکته مهم درباره ذخیره‌سازی
اطلاعات فقط در حافظه‌ی همان مرورگر و همان دستگاه ذخیره می‌شوند؛ پاک کردن داده‌های مرورگر ممکن است اطلاعات را حذف کند. این نسخه همگام‌سازی ابری یا پشتیبان‌گیری خودکار ندارد. برای احتیاط، داده‌های مرورگر را پاک نکن.

## اجرای آزمایشی
می‌توان index.html را مستقیم در مرورگر باز کرد؛ در این حالت امکانات اصلی و ذخیره‌سازی محلی کار می‌کنند، اما نصب PWA و حالت آفلاین کامل به میزبانی HTTPS نیاز دارد.

نسخه‌ی فعلی برای آبان ۱۴۰۵ تنظیم شده است.
